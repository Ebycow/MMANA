# 鋭い V の分割数

v-angle の 10° と 20° の V 型ダイポールで、腕の分割数を変える。頂点の近くでは区間の長さと 2 本の距離の比が分割数によらない（20° で 5.8、10° で 11.5）ので、区間が短いほど影響を受ける範囲が狭くなるはず。基準はなく、分割 2 倍での変化で見る。

## 警告と測定の一致

この実験で出るべき警告：`CloseWires`。共振のずれ（基準との差、なければ分割 2 倍での変化）が 0.5 % を超えるケースに出ること、0.25 % 未満のケースには出ないことを確かめる。

すべて一致。
