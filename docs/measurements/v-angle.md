# 給電点での折れ角（V 型ダイポール）

長さ 0.24 λ の腕 2 本を給電点で V 字につなぎ、腕どうしの角度を変える（180° はまっすぐなダイポール）。腕は各 20 分割、半径 1 mm。角度で共振は物理的に変わるので基準はなく、分割 2 倍での変化と AGT で見る。

`cargo run --release -p mmana-measure -- run v-angle --out docs/measurements` で生成（手で編集しない）。列の意味は [README](README.md#表の見方)。
