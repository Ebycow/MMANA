# 腕の途中での折れ角

ダイポールの各腕を中ほどで折り曲げ、折れ目の内側の角度を変える（180° はまっすぐ、小さいほど折り返す）。各区間 10 分割、半径 1 mm。基準はなく、分割 2 倍での変化と AGT で見る。

`cargo run --release -p mmana-measure -- run bend-angle --out docs/measurements` で生成（手で編集しない）。列の意味は [README](README.md#表の見方)。
