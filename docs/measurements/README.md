# 計算結果を信用できない形の測定

MININEC が苦手とする形を 1 つずつ取り出し、その度合いを変えたときに共振周波数・給電点の抵抗・利得がどれだけ動くかを測った結果です（[#16](https://github.com/Ebycow/MMMANA/issues/16)）。
警告を足すかどうか、どのしきい値にするかは、ここの数値から決めます。

この版は**選別（スクリーニング）**の結果です。どの候補に影響があるかを粗く調べました。影響のあった候補は、警告にする前に条件を細かく変えて測り直します。

## 測り方

```sh
cargo run --release -p mmana-measure -- list                                 # 実験の一覧
cargo run --release -p mmana-measure -- run --all --out docs/measurements    # 表を作り直す（数秒）
cargo run --release -p mmana-measure -- dump folded-segments --out /tmp/f    # 各ケースを .maa に書き出す（アプリで開ける）
```

各表（`<実験>.md`）はこのコマンドが生成します。手で編集しないでください。このページだけが手書きです。

アンテナはすべて 14.05 MHz 用で、自由空間に置いた損失なしのワイヤーです。基本は長さ 0.48 λ の半波長ダイポールで、そこから 1 つの点だけを変えています。

### 表の見方

| 列 | 意味 |
|---|---|
| 共振 | 給電点のリアクタンスが 0 になる周波数（[共振周波数の探索](../porting-notes.md#共振周波数の探索と推測計算)で、14.05 MHz の半分〜2 倍から探す）。「なし」は範囲に共振がない |
| 基準との差 | 同じアンテナを、正しいと考えられる別の書き方で計算した共振周波数との差。同じ物理を書き分けられる実験だけにある |
| 分割 2 倍での変化 | すべてのワイヤーの分割数を 2 倍にしたときの共振周波数の変化。分割が足りないことによる誤差の目安。正しいモデルなら 0 に近づく |
| R | 共振での給電点の抵抗（共振がなければ 14.05 MHz での値） |
| 最大利得 | 全方向で最大の利得 |
| AGT | 平均利得テスト。全方向に放射した電力の合計 ÷ 入力電力（dB）。損失のないアンテナでは 0 dB になるはず |
| 破綻（R ≤ 0） | 入力電力が 0 以下で、MININEC の計算が成り立っていない |

## 選別の結果

実物との差（工作の誤差など、数 %）は、ユーザーが実物の調整で吸収する前提です。そのため、エンジン側の誤差が共振周波数で 0.5 % を超えるかどうかを、いったんの目安にしています。

| 実験 | 何を変えたか | 結果 | 判定 |
|---|---|---|---|
| [folded-segments](folded-segments.md) | 近接した平行ワイヤーの、区間の長さ ÷ 間隔 | **区間の長さが間隔の約 4.5 倍を超えると計算が破綻する**。共振が +6〜16 % ずれ、R は 286 Ω が 1.7〜14 Ω になる。4.3 以下では 0.1 % 以内。間隔 10 cm と 5 cm で同じ比（4.3 と 4.7 の間）を境に切り替わるので、効いているのは間隔そのものではなくこの比 | **影響大。最優先で警告にする** |
| [v-angle](v-angle.md)・[bend-angle](bend-angle.md) | 給電点・腕の途中での折れ角 | 角度が小さいほど、分割 2 倍での変化が大きくなる（180° で 0.06 %、90° で 0.5 %、30° で 0.7〜0.8 %）。20° 以下で急に 2.8〜5.8 % に跳ぶ | **影響あり**。20° での跳びは、折れ目の近くの 2 本の区間が「区間の長さ ÷ 距離 ≒ 5.8」になっているためと考えられる（30° では 3.9）。folded-segments と同じ原因の可能性が高い |
| [segment-step](segment-step.md) | 接続部で隣り合う区間の長さの比 | 内側が λ/17 のとき、比 3.3 で −1.0 %、比 10 で −3.1 %。内側が λ/50 のときは、比 10 でも −0.17 %、比 15 で −0.73 % | **影響あり**。比だけでなく区間の粗さとの組み合わせで決まる。詳しく測る |
| [segments](segments.md) | 分割数（区間の長さと波長の比） | λ/12 で −0.4 %、λ/8 で −1.5 %、λ/4 で −8 %。λ/17 より細かければ 0.1 % 以内 | **影響あり**（固定分割数で粗くしたとき）。MMANA の自動分割（既定は λ/400〜λ/40）では起きない |
| [segment-radius](segment-radius.md) | 区間の長さ ÷ 半径（太いワイヤー） | 区間の長さが半径の 3 倍以上なら、分割 2 倍での変化は 0.4 % 以内。2 倍で R が +3.7 Ω 動く。1 倍では共振が見つからない | 影響は小さい。極端に太いときだけ |
| [folded-radius](folded-radius.md) | 近接した平行ワイヤーの、間隔 ÷ 半径 | 間隔が半径の 2.5 倍まで近づけても、分割 2 倍での変化は 0.4 % 以内 | 影響は小さい |
| [radius-step](radius-step.md) | 接続部での半径の段差 | 段差 20 倍でも、分割 2 倍での変化は 0.1 % 前後で、AGT も 0 dB | **この方法では測れない**。MININEC の半径の段差の扱いは、分割を増やしても消えない系統的な誤差として知られている。確かめるには外部の基準（NEC2 や実測）が要る |

### 分かったこと

- **AGT は MININEC の破綻を検出しなかった。** folded-segments で R が 1/50 になった壊れたケースでも、AGT は −0.01〜−0.65 dB にとどまりました（R が 6.22 Ω のケースで −0.01 dB）。MININEC では入力電力と放射電力のつじつまが合ったまま、値そのものがずれるためと考えられます。AGT は警告の指標には使いません。
- **分割 2 倍での変化は、破綻をよく検出した。** folded-segments では、壊れたケースはすべて 2.7 % 以上、正常なケースはすべて 0.2 % 未満でした。そのアンテナ自体を分割 2 倍で計算し直す「精度チェック」は、原因を問わない確認方法として有効そうです。
- **0.1 % 未満の差は、この方法では区別できない。** segments では、分割を細かくしても共振が 0.1 % ほど揺れます（14 分割で基準から +0.09 %、80 分割で −0.06 %）。

## 測れていないもの

| 候補 | 理由 |
|---|---|
| リアルグランド上の低いアンテナ、地面から給電する垂直系 | MININEC は電流を完全導体の大地で計算するので、MININEC の中だけでは正解を作れない。NEC2 などの外部の基準が要る |
| 接続部での半径の段差 | 同上（上表） |
| 給電点の位置（3 本以上が集まる点など）、一部だけ重なるワイヤー（#13）、周波数によって分割が変わること | 次の段階で実験を足す |

## 次の段階

1. **近接した平行ワイヤー**：しきい値（区間の長さ ÷ 間隔 4.3〜4.7）が、間隔・半径・ワイヤーの長さ・角度を変えても同じかを確かめ、警告にする。折れ角の 20° での跳びが同じ原因かも確かめる。
2. **接続部の区間の長さの比**：比と区間の粗さの組み合わせで誤差のモデルを作る。
3. **折れ角**：角度と分割の組み合わせで測り直す。
4. **精度チェック**（分割 2 倍で計算し直す機能）を、原因を問わない確認方法として検討する。
