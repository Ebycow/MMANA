# 計算結果を信用できない形の測定

MININEC が苦手とする形を 1 つずつ取り出し、その度合いを変えたときに共振周波数・給電点の抵抗・利得がどれだけ動くかを測った結果です（[#16](https://github.com/Ebycow/MMMANA/issues/16)）。
警告は、ここで測ったしきい値で出し、測定と食い違わないことをテストで確かめています。

## 測り方

```sh
cargo run --release -p mmana-measure -- list                                 # 実験の一覧
cargo run --release -p mmana-measure -- run --all --out docs/measurements    # 表を作り直し、警告と測定の一致を確かめる（20 秒ほど）
cargo run --release -p mmana-measure -- dump folded-segments --out /tmp/f    # 各ケースを .maa に書き出す（アプリで開ける）
```

各表（`<実験>.md`）はこのコマンドが生成します。手で編集しないでください。このページだけが手書きです。

アンテナは、`samples` 以外はすべて 14.05 MHz 用で、自由空間に置いた損失なしのワイヤーです。基本は長さ 0.48 λ の半波長ダイポールで、そこから 1 つの点だけを変えています。

### 表の見方

| 列 | 意味 |
|---|---|
| 共振 | 給電点のリアクタンスが 0 になる周波数（[共振周波数の探索](../porting-notes.md#共振周波数の探索と推測計算)で、設計周波数の半分〜2 倍から探す）。「なし」は範囲に共振がない |
| 基準との差 | 同じアンテナを、正しいと考えられる別の書き方で計算した共振周波数との差。同じ物理を書き分けられる実験だけにある |
| 分割 2 倍での変化 | すべてのワイヤーの分割を 2 倍にしたときの共振周波数の変化（固定分割数は 2 倍、自動分割・テーパーは DM1・DM2 を 2 倍）。分割が足りないことによる誤差の目安 |
| R | 共振での給電点の抵抗（共振がなければ設計周波数での値） |
| 最大利得 | 全方向で最大の利得 |
| AGT | 平均利得テスト。全方向に放射した電力の合計 ÷ 入力電力（dB）。損失のないアンテナでは 0 dB になるはず |
| 警告 | そのケースを計算したときに出る警告（`CalcWarning` の `code`） |
| 破綻（R ≤ 0） | 入力電力が 0 以下で、MININEC の計算が成り立っていない |

### 警告と測定の一致

共振のずれ（基準との差、なければ分割 2 倍での変化）を誤差とし、許容値を **0.5 %** とします。実物との差（工作の誤差など、数 %）はユーザーが実物の調整で吸収する前提なので、計算側の誤差はそれより十分小さくあるべきだからです（`report::TOLERANCE`）。

- 各実験は「出るべき警告」（`catches`）を持ちます。誤差が 0.5 % を超えるケースにその警告が出ていなければ、不一致です。
- 実験が扱う警告（どれかの実験の `catches` にあるもの）が、誤差 0.25 % 未満のケースに出ていれば、不一致（誤報）です。これは `samples` を含むすべての実験で確かめます。
- 0.25〜0.5 % は、出ても出なくても構わない範囲です。

`run` は不一致があると失敗し、`cargo test` でも全ケースを確かめます（`warnings_match_the_measurements`）。

## ハーネスから警告までの手順

1. **実験を足す**（`crates/mmana-measure/src/experiments.rs`）。疑わしい形の度合いを 1 つだけ変えたアンテナの族を作ります。同じ物理を別の書き方で表せるなら、それを基準にします。
2. **測る**（`run`）。表を見て、誤差が 0.5 % を超える範囲を確かめます。原因が 1 つに絞れないときは、条件を切り分ける実験を足します（下の折り返しダイポールでは 4 つ足しました）。
3. **ルールを作る**（`crates/mmana-core/src/checks.rs`）。しきい値は定数にし、根拠の表をコメントに書きます。エンジンの判定をそのまま使えるなら、それを記録するのがいちばん正確です。`WarningCode` を足し、警告にワイヤー番号を付けます。
4. **実験の `catches` にその警告を書き、`run --all` で一致を確かめる。** 不一致が出たら、ルールかしきい値を直して 2 に戻ります。サンプルへの誤報もここで分かります。
5. **エンジンのテストを足す**（しきい値の両側。`tests/properties.rs`）。
6. **画面に出す**（`apps/desktop/src/domain/diagnostics.ts` の `RULES` と `WARNING_RULE` に 1 行ずつ）。ワイヤー表と 3D 表示に出て、設定で切り替えられるようになります。
7. **このページと `docs/guarantees.md` に書く。**

## 警告にしたもの

### `CloseWires`：つながったワイヤーの横の点を、ワイヤー上の点として計算している

MININEC は、観測点に近い区間を、その区間と同じワイヤー上の点として近似して計算します（`kernel.rs` の `l135`）。ワイヤーが「同じ」かどうかの判定は、2 本が同じ接続点を共有しているかだけを見て、観測点が区間の楕円（両端までの距離の和 ≦ 区間の長さ × 1.1）の中にあれば近似を使います。

そのため、つながった別のワイヤーが区間の**横**を通っていると、その上の点も「区間上の点」として計算されます。

- **折り返しダイポールの端**：端の短いワイヤーとつながった長いワイヤーの区間の横に、もう一方の長いワイヤーの観測点が来ます。区間の長さが間隔の **4.36 倍**（区間の中央の横にある点が楕円に入る比）を超えると、共振が +6〜16 % ずれ、286 Ω が 1.7〜14 Ω になります（[folded-segments](folded-segments.md)）。
- **鋭い V の頂点**：もう一方の腕の観測点が楕円に入ります（約 27° より鋭いとき）。腕どうしが 20° で −2.8 %、10° で −5.2 %（[v-angle](v-angle.md)・[bend-angle](bend-angle.md)）。

**つながっていない**平行な 2 本（[parallel-pair](parallel-pair.md)、区間 ÷ 間隔 10 でも 0.19 %）や、端だけ細かく分けた折り返しダイポール（[folded-tapered](folded-tapered.md)）では、この近似が使われないので問題は出ません。最初に疑った「近接した平行ワイヤー」そのものは原因ではありませんでした。

ルール（`checks::misapplied_shortcut`）：エンジンが行列を作るときに、この近似を使った点のうち、**区間の横**（区間の端より外側ではない）にあり、ワイヤーの半径より離れているものを記録します。そのうち次の 2 つを満たすものがあれば警告します。

| 条件 | 値 | 根拠 |
|---|---|---|
| 区間の長さ ÷ 点までの距離 | 4 以上（`SHORTCUT_RATIO`） | 折り返しダイポールは 4.36 から破綻する。HB9CVH の給電線（34° でつながる）は 2.1 で、結果は動かない（[samples](samples.md)） |
| 区間の長さ | λ/250 より長い（`SHORTCUT_WAVELENGTHS`） | 鋭い V は λ/167 の区間で 1.1〜2.1 %、λ/333 で 0.36 % 以下（[v-segments](v-segments.md)）。頂点を λ/400 までテーパーで細かくした 10° のダブルダイポール（DBLDP）は動かない |

警告には 2 本のワイヤー番号と、警告が出なくなる区間の長さを書きます。区間の長さを、点までの距離の 4 倍か λ/250 より短くすれば、近似は使われても誤差は許容値に収まります。

## 選別の結果

| 実験 | 何を変えたか | 結果 | 判定 |
|---|---|---|---|
| [folded-segments](folded-segments.md)・[folded-tapered](folded-tapered.md)・[parallel-pair](parallel-pair.md) | 近接した平行ワイヤー | 上記のとおり。破綻するのは、つながった端のある折り返しダイポールだけ | **`CloseWires` で警告** |
| [v-angle](v-angle.md)・[bend-angle](bend-angle.md)・[v-segments](v-segments.md) | 給電点・腕の途中での折れ角 | 20° 以下は `CloseWires` で警告。30〜90° でも分割 2 倍での変化が 0.5〜0.8 % ある | **20° 以下は警告。30〜90° は未対応**（原因は別。詳しく測る） |
| [crossing](crossing.md) | つながずに交差するワイヤー | 90° では 3 mm まで近づけても変化なし。20° で 1 cm 以内に近づけると 0.75〜1.1 % | 未対応。たすき掛けの位相線はふつう 90° に近いので、優先度は低い |
| [segment-step](segment-step.md) | 接続部で隣り合う区間の長さの比 | 内側が λ/83 のとき、比 3.3 で −1.0 %、比 10 で −3.1 %。内側が λ/250 のときは比 10 でも −0.17 %、比 15 で −0.73 % | **未対応**。比と区間の粗さの組み合わせで決まる。詳しく測る |
| [segments](segments.md) | 分割数（区間の長さと波長の比） | λ/12 で −0.4 %、λ/8 で −1.5 %、λ/4 で −8 %。λ/17 より細かければ 0.1 % 以内 | 未対応（固定分割数で粗くしたとき）。MMANA の自動分割（既定は λ/400〜λ/40）では起きない |
| [segment-radius](segment-radius.md) | 区間の長さ ÷ 半径（太いワイヤー） | 区間の長さが半径の 3 倍以上なら、分割 2 倍での変化は 0.4 % 以内。2 倍で R が +3.7 Ω 動く。1 倍では共振が見つからない | 影響は小さい。極端に太いときだけ |
| [folded-radius](folded-radius.md) | 近接した平行ワイヤーの、間隔 ÷ 半径 | 間隔が半径の 2.5 倍まで近づけても、分割 2 倍での変化は 0.4 % 以内 | 影響は小さい |
| [radius-step](radius-step.md) | 接続部での半径の段差 | 段差 20 倍でも、分割 2 倍での変化は 0.1 % 前後で、AGT も 0 dB | **この方法では測れない**。分割を増やしても消えない系統的な誤差として知られているので、確かめるには外部の基準（NEC2 や実測）が要る |

### 分かったこと

- **AGT は MININEC の破綻を検出しなかった。** 折り返しダイポールで R が 1/50 になった壊れたケースでも、AGT は −0.01〜−0.65 dB にとどまりました（R が 6.22 Ω のケースで −0.01 dB）。MININEC では入力電力と放射電力のつじつまが合ったまま、値そのものがずれるためと考えられます。AGT は警告の指標には使いません。
- **分割 2 倍での変化は、破綻をよく検出した。** 折り返しダイポールでは、壊れたケースはすべて 2.7 % 以上、正常なケースはすべて 0.2 % 未満でした。ただし鋭い V の頂点のように、分割を細かくしても同じ近似が残る形では、変化が小さく出ることがあります。
- **0.1 % 未満の差は、この方法では区別できない。** segments では、分割を細かくしても共振が 0.1 % ほど揺れます（14 分割で基準から +0.09 %、80 分割で −0.06 %）。

### 警告のないまま結果が動くサンプル

[samples](samples.md) で、分割 2 倍での変化が 0.5 % を超えるのに警告が出ないものです。原因はまだ調べていません。

| サンプル | 分割 2 倍での変化 |
|---|---|
| 6SKYDOOR | +89 %（別の共振を見つけている可能性が高い） |
| 4X12 | −15 % |
| FEEDER | −8.7 % |
| DP160LD | −2.2 % |
| VDP40B | −2.0 % |
| TWINLOOP | +0.76 % |
| 12EL430 | −0.55 % |

ほかに、分割 2 倍で共振が見つからなくなるもの（MAGLOOP2・MAGLOOPM・MAGLOOPT・RHOMBIC・VDP40、表で「—」）があります。

## 測れていないもの

| 候補 | 理由 |
|---|---|
| リアルグランド上の低いアンテナ、地面から給電する垂直系 | MININEC は電流を完全導体の大地で計算するので、MININEC の中だけでは正解を作れない。NEC2 などの外部の基準が要る |
| 接続部での半径の段差 | 同上（上表） |
| 給電点の位置（3 本以上が集まる点など）、一部だけ重なるワイヤー（#13）、周波数によって分割が変わること | 次の段階で実験を足す |

## 次の段階

1. 警告のないまま結果が動くサンプル（上表）の原因を調べる。
2. 30〜90° の折れ角、接続部の区間の長さの比を、条件を変えて測り、誤差のモデルを作る。
3. そのアンテナ自体を分割 2 倍で計算し直す「精度チェック」を、原因を問わない確認方法として検討する。
